# SAP-1

SAP-1 (Simple-As-Possible-1) is a bus-organized 8-bit CPU designed by Albert Paul Malvino in his book *Digital Computer Electronics*.

This is an implementation of SAP-1 in Verilog, along with an assembler written in C99.

# Assembler

The assembler translates human-readable assembly code (like the example below) into binary machine code that can be executed by the SAP-1 CPU. 

Every SAP-1 assembly program must contain a `.data` section for defining variables and a `.text` section for instructions. The output is a `.bin` file that the Verilog testbench can load and simulate.

### Example

```asm
    .data   ; Data section (must appear before .text)

a = 19      ; 8-bit unsigned variable
b = 43      ; 8-bit unsigned variable

    .text   ; Program section

_start:     ; Program entry point

    LDA a   ; Load a into the accumulator
    
    ADD b   ; Add b to the accumulator
    
    OUT     ; Output accumulator value
    
    HLT     ; Halt execution
```

# Simulation

For simulation, you'll need to install [iverilog](https://github.com/steveicarus/iverilog) and [cocotb](https://docs.cocotb.org/en/stable/install.html).

> [!WARNING]
> This project has been tested only on **cocotb 1.9.2**. Newer versions may not be compatible and are currently unsupported. If you encounter issues, install cocotb 1.9.2
> ```bash
> $ pip install "cocotb~=1.9.2"
> ```

You will also need a C compiler (e.g., `gcc`, `clang`) for compiling the assembler. By default `gcc` is used, but you can configure `Makefile.conf` to use a different compiler.

You can:
- Compile the assembler
- Assemble the tests (add.asm, sub.asm and arith.asm)
- Simulate the tests
- Display test results

By simply running

```bash
$ make
```

In the root directory of the repository.

The assembler binary along with the compiled test binaries will be saved on `build/bin`
Simulation files generated by [iverilog](https://github.com/steveicarus/iverilog) will be saved on `build/`

You can run specific tests individually, for example to test `add.asm` run

```bash
$ make test_add
```

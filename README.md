# SAP-1

SAP-1 (Simple-As-Possible-1) is a bus-organized 8-bit CPU designed by Albert Paul Malvino in his book *Digital Computer Electronics*.

This is an implementation of SAP-1 in Verilog, along with an assembler written in C99.

# Assembler

The assembler translates human-readable assembly code (like the example below) into binary machine code that can be executed by the SAP-1 CPU. 

Every SAP-1 assembly program must contain a `.data` section for defining variables and a `.text` section for instructions. The output is a `.bin` file that the Verilog testbench can load and simulate.

### Example

```asm
.data       ; begin .data section, this section must exist and
            ; come before the .text section

a = 19      ; variable 'a' assigned to 19
            ; variables are to be 8-bit long unsigned integers

b = 43      ; variable 'b' assigned to 43

.text       ; begin .text section

_start:     ; entry point must exist with the label _start

    LDA a   ; load the variable 'a' to the accumulator register

    ADD b   ; add the accumulator's content to the variable 'b'
            ; store the result in the accumulator register

    OUT     ; display the accumulator's content in the display port

    HLT     ; halt the CPU
```

# Usage

For simulation, you'll need to install [iverilog](https://github.com/steveicarus/iverilog) and optionally [gtkwave](https://github.com/gtkwave/gtkwave) for viewing waveform files.

You will also need a C compiler (e.g., `gcc`, `clang`) - for compiling the assembler, by default gcc is used, but you can configure assembler/Makefile to use a different compiler.


To compile the assembler, assemble the tests, simulate the tests, display outputs, and generate waveforms, simply run

```bash
$ make
```

The assembler binary output will be saved on `out/bin`. Simulation files generated by [iverilog](https://github.com/steveicarus/iverilog) will be placed in `out/`, and the compiled test binaries on `testbench/binary/`


You can run specific tests individually, for example to test `add.asm` run

```bash
$ make test_add
```


To view waveforms using `gtkwave` run

```bash
$ make show_add
```
